# NexusBoard

![CI](https://github.com/Ankitavasudev/NexusBoard/actions/workflows/ci.yml/badge.svg)

Real-time collaborative whiteboard for teams with live drawing, sticky notes, and brainstorming.

## Features

- **Real-time Collaboration** - Multiple users can draw simultaneously
- **Drawing Tools** - Pen, shapes, text, sticky notes
- **Live Cursor** - See other users' cursors in real-time
- **Export** - Save boards as PNG or JSON
- **Templates** - Pre-built templates for common workflows

## Tech Stack

- React.js
- Socket.io
- Canvas API
- Node.js

## Installation

`ash
npm install
npm start
`

## Usage

1. Open the app in your browser
2. Share the room code with your team
3. Start drawing and collaborating!
